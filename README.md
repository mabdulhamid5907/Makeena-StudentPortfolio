# Student Portfolio & Academic Planner (COS 106)

A static multi-page website built with plain HTML, CSS and JavaScript. No frameworks or build step.

## Pages
- `index.html` Home: name, photo, welcome message, navigation, biography
- `about.html` Education, career aspirations, skills, hobbies, results table, video and audio
- `projects.html` Three projects with images and links, filterable
- `planner.html` Academic planner: add, complete, delete tasks (saved in localStorage)
- `contact.html` Contact form with JavaScript validation
